# Malware Concept Drift Detection

**Malware-Concept-Drift-Detection** provides a pipeline for detecting concept drift in a collection of malware PE files.

The project includes multiple repositories to:

1. Extract **Decoding-the-Secrets** and/or **EMBER** features;
2. Perform a train/test data split;
3. Detect concept drift using **Transcendent**, leveraging Conformal Evaluation.

## Usage

To run the pipeline, follow the instructions provided in the [Bootstrap](https://github.com/Malware-Concept-Drift-Detection/bootstrap) repository.
